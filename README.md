# Cover status

Uptime monitor for [covergiving.com](https://covergiving.com): checks the site, sign-in and checkout every 5 minutes.
If something goes down, a GitHub issue opens and is assigned to the owner (that sends an email). Status page: https://wendle36508.github.io/cover-status/

Settings live in `.upptimerc.yml` (a copy is kept in the Cover repo at `ops/upptime/.upptimerc.yml`). Powered by [Upptime](https://upptime.js.org).
